# Skrip VO: "Pulau Batu Puteh: Kalah Sebab Sepucuk Surat" (draf 1, ≈58 s)

Gaya: MAP ANIMATION (sejarah + plot twist). Fakta: `research/pulau-batu-puteh.md`.
Hook: pulau kecil dekat Johor tapi milik Singapura + open loop "puncanya sepucuk surat". Re-hook: "Tapi tunggu dulu!" sebelum surat 1953.

Pulau ni cuma sebesar padang bola, empat belas kilometer je dari Johor. Tapi hari ni, ia milik Singapura! Dan puncanya, sepucuk surat! Namanya Pulau Batu Puteh. Tahun lapan belas lima puluh, British bina Rumah Api Horsburgh atas pulau ni, dan rumah api tu dijaga dari Singapura lebih seratus tahun. Tahun sembilan belas tujuh puluh sembilan, Malaysia terbitkan peta, letak pulau ni dalam wilayah kita. Singapura bantah, dan kes ni dibawa ke Mahkamah Antarabangsa. Tapi tunggu dulu! Muncul sepucuk surat dari tahun sembilan belas lima puluh tiga. Pegawai Johor sendiri tulis: Kerajaan Johor tak tuntut pemilikan pulau ni! Tahun dua ribu lapan, keputusan dua belas lawan empat. Pulau Batu Puteh milik Singapura. Tapi Batuan Tengah, jatuh pada Malaysia. Kalau kau, patut ke Malaysia cuba tuntut semula? Komen kat bawah!
